# 말씨앗

아는 한자어가, 그대로 일본어가 된다。韓国語を話す人のための、日本語の語彙アプリ。知っている韓国語の漢字語（학생）を打つと、
同じ漢字・同じ意味の日本語の語（学生 がくせい）と、字ごとの 소리 짝（학 → がく、생 → せい）が出る。あつめた 소리 짝 だけで
言える漢字語が、まとめて増えていく（학생＋대학 → 대학생 だいがくせい）。画面は韓国語。思想は [CONCEPT.md](CONCEPT.md)。

名前は 말（言葉）＋씨앗（種）。前の名前は ことのはし で、中の名前（`kotonohashi`：端末の DB・localStorage・書き出し、Supabase の `kh_`、
ことのあめ の つなぐ の `app`。例文の `hashi-*.json` も）は前のまま（変えると、端末の記録が読めなくなる）。

글씨앗（`../kanji`、覚えた日本語の語から入る漢字のアプリ）を分けて作ったもの。辞書・字の音のしくみ・例文・覚え具合・端末内保存・
引き継ぎのリンクは 글씨앗 と同じ作りで、入口と見せる中心を、韓国語の漢字語と 소리 짝 にした。ことのね（`../hanjaatume`）・글씨앗 の姉妹。

## 画面

| タブ | 中身 |
|---|---|
| 모으기 `/` | 知っている漢字語を打つ（학생。日本語のかな・ローマ字・漢字でも引ける）。「학생 → 学生 がくせい · 같은 한자어 · 뜻도 같아요」と 소리 짝 の根（意味・使い方のちがう語は「한국어와 다른 점이 있어요」と、そのちがい）。「모으면, 일본어로 말할 수 있는 한자어가 ◯개 늘어나요」。日本語では別の漢字で言う語（공부 → 勉強、편지 → 手紙）と、同じ漢字で意味を確かめたい語（工夫 くふう 궁리）も並べる。同じ音の漢字語が二つ以上なら選ぶ。いちばん上に「일본어로 말할 수 있는 한자어」の数 |
| 찾기 `/find` | 文で出会う（글씨앗 と同じ）。말할 수 있는 한자어 `?view=readable`（集めた 소리 짝 だけで言える、同じ漢字・同じ意味の漢字語。上から 말해 보기 `?view=read`＝韓国語の語と漢字を見て日本語を打つ と、써 보기 `?view=write`）、한 짝만 더 `?view=near` |
| 단어 `/words` | 集めた語（韓国語の漢字語を先に）と覚え具合。복습（말하기＝한자어 → 일본어 と 쓰기＝일본어 → 한자）、모은 단어 써 보기 |
| 소리 짝 `/hanja` | 集めた 소리 짝 を、韓国語の音の받침ごとに（받침 없음・ㄱ・ㄴ・ㄹ・ㅁ・ㅂ・ㅇ・그 밖、訓読みは別）。並べると対応が見えてくる。ほかに 모은 한자・상용한자 2136・조합하기、字のページ（この字で書く言葉） |
| 나 `/me` | これまでの数（모은 한자어・한자・소리 짝・말할 수 있는 한자어）、表示、계정（ことのあめ のアカウント。任意）、書き出し・読み込み、引き継ぎのリンク、姉妹アプリ、出典 |

## 글씨앗 から変えたところ

- **辞書**（`scripts/build-data.mjs`）：語に `ks`（同じ漢字の韓国語の語と意味も同じ：한국어기초사전 の対訳がこの語を指すか、この語の韓国語の
  意味にその語がある）と `kl`（その韓国語の語をどれくらいよく使うか：1 초급 … 5 ほとんど使わない）を書く。元ファイルは 글씨앗 の
  `../kanji/scripts/.cache` と ことのね の `../hanjaatume/scripts/.cache` から読む。
- **言える語**（`src/data/combine.ts` の `sameHanjaeo`）：読める語・あと1音（한 짝만 더）・あつめると言える語は、`ks` で、韓国語でも使う（`kl` 4 まで）
  漢字語だけ。並びは JLPT の級 → 韓国語でよく使う語 → 字幕での頻度。
- **韓国語から引く**（`src/data/resolver.ts` の `resolveKoreanGroups`）：同じ漢字・同じ意味（same）／意味は同じで別の漢字（meaning：공부 → 勉強）／
  同じ漢字で意味を確かめたい（kanji：공부 → 工夫）の三つ。意味が違うと決めつけず、意味を並べる。
- **한국어와 다른 점**（`scripts/same-hanjaeo.json`）：同じ漢字語のうち、日本語と韓国語で意味・使い方のちがう語に、ちがいを韓国語で書いた `kd`
  （생도 → 生徒「中高生や受講生のこと。사관생도 の意味は無い」、계산 → 計算「お店の 계산 は お会計」、사치 → 奢侈「日本語ではまず使わない。贅沢」）。
  「같은 한자어 · 한국어와 다른 점이 있어요」と、모으기・語のシート・말해 보기 に出す（`src/components/DiffNote.tsx`）。643語。
  読みによって意味の合わない語（人事 ひとごと ↔ 인사 など21語）は `ks: false` で同じ漢字語から外し、韓国語の語の形を直した語
  （到底 → 도저히 など3語）もここに書く。말씨앗 が同じ漢字語として出す約6,200語を AI で一語ずつ見直し、その提案を一件ずつ確かめて書いた。
  韓国語の意味の誤り（対訳が同音の別の語を指していた・差別語が入っていた など223語）は `scripts/glosses-ko.json` で直した（글씨앗 も同じ）。
- **見せ方**：語の行・シート・あつめる は韓国語の漢字語を先に（학생 → 学生 がくせい）。根のいちばん上に 소리 짝（학 → がく）。
  말해 보기 は韓国語の語と、字の下に韓国語の音。
- **例文**（`scripts/build-sentences.mjs`）：印（押せる・また出会ったと数える語）は、同じ漢字・同じ意味の漢字語だけ（`sameHanjaeo` と同じ決まり）。
  ほかの漢字の語（奥さん・難しい・働く）は `r` に分け、ふりがなだけを添える（押せない・数えない）。漢字語の無い文は入れない
  （約5,200文。うち約2,000文は 말씨앗 のために書いた文。下の「例文を書き足す」）。
- 端末のデータは別（DB `kotonohashi`、localStorage `kotonohashi.`、書き出し `app: "kotonohashi"`、Supabase の名前は `kh_`）。글씨앗 と混ざらない。

## 開発

```bash
npm install
npm run dev              # 開発サーバ（http://localhost:5173）
npm run build            # 本番ビルド
npm run test             # ユニットテスト
npm run build:data       # 辞書（public/data/words.json・kanji.json、src/data/curated-*.json）
npm run build:sentences  # 例文（public/data/sentences.json）
```

辞書・例文の作り方、データの出典は 글씨앗 と同じ（[NOTICE.md](NOTICE.md)、`scripts/build-data.mjs` の先頭）。

## 例文を書き足す

ことのあめ の文に出てこない漢字語のために、文を書き足している（`scripts/sentences/hashi-*.json`。말씨앗 と 글씨앗 の
`build:sentences` が読む）。一文は `{"word": "支援|しえん", "ja": "…", "ko": "…"}`（word は、その文を書いた目当ての語）。

- `hashi-ab.json`：JLPT N5–N3 の漢字語と、N2–N1・よく使う語のうち韓国語で 초급・중급 の漢字語に、1語2文まで（1,974文）。
  これで、その2,046語のうち2,039語に例文が2文以上ある。残りは、形態素解析がその読みを出さない6語（市場 いちば・博士 はくし など）と、
  「한국어와 다른 점」に合わない文を外した 女史（1文）。
  AI が書いた下書きで、韓国語・日本語を話す人の確認はまだ（`"reviewed": false`）。確かめるときの目の付けどころは
  [scripts/sentences/REVIEW.md](scripts/sentences/REVIEW.md)。
- 書き足すときは、`node scripts/sentences/check.mjs <文の json>` で確かめてから `hashi-<名前>.json` として置く。目当ての語が
  말씨앗 の漢字語か、文で出会う と同じ印の付け方でその語（表記と読み）として拾えるか（長い語の一部になっていないか・別の読みに
  取られていないか）、韓国語の訳に同じ漢字語かその語の韓国語の意味が入っているか、長さ（日本語 40 字・韓国語 60 字まで）、
  ほかの文と同じでないかを見る。
- 印の付け方は `scripts/sentences/marker.mjs`。글씨앗 の `scripts/sentences/marker.mjs` も同じもの（直すときは両方）。

## アカウント（ことのあめ、任意）

글씨앗 と同じ作り（글씨앗 の README の「アカウント」）。姉妹アプリ ことのあめ のアカウントでログインでき（나 の「계정」から
`ことのあめ로 연결하기` か、メールアドレスとパスワード）、集めた語と覚え具合をアカウントにも置いて端末の記録と合わせる
（`kh_records`、`supabase/records.sql`。`src/util/account.ts`・`src/util/connect.ts`・`src/data/record.ts`）。ことのあめ 側の画面とメールは、
말씨앗 から来たときは韓国語。戻り先の `/login` は `vercel.json` で開けるようにしてある。

## 紹介映像

`promo/` は別のプロジェクト（Remotion 4、1920×1080・約92秒・韓国語の字幕とナレーション・合成の音楽）。アプリの画面を描き直して、
소리 짝 で言える語が増えるしくみ（회・사・원 の三つで5語 → 24の짝で55語、회의 をあつめて +8、교회 を きょうかい と言えた）を見せる。
ことのね の映像と同じ作り。ほかに、ホーム画面への追加のしかた（縦の映像、韓国語）もある。作り方は [promo/README.md](promo/README.md)。

## まだのこと

- アイコンとリンクのカード（og.png）は ことのね のまま／まだ無い。アイコンを替えたら、紹介映像も（`promo/` で `npm run assets` のあと）書き出し直す。
- `.env` に ことのあめ の Supabase を入れた（アカウント・使われ方の数・みんなの雨）。表と関数はまだ当てていないので、ことのあめ のリポジトリで
  `supabase/usage.sql`・`falls.sql`・`records.sql`（名前は `kh_`）を当てる（`node --env-file=.env.local scripts/migrate.mjs ../hanjaeo/supabase/records.sql`
  など）。当てるまでは、ログインはできても記録を合わせられず、みんなの雨も降らない。
- 公開先は https://kanji-delta.vercel.app/（Vercel のプロジェクト名は kanji）。ことのあめ の `src/lib/sisters.ts` の `kotonohashi` の `url` に書いてある（書くまでは つなぐ が「연결할 수 없어요」になっていた）。Vercel の環境変数にも `VITE_SITE_URL` を入れる（無いと使われ方の数が送られず、リンクのカードの og:url も空）。
- 書き足した例文（`scripts/sentences/hashi-ab.json`）は下書き。韓国語を話す人に訳の自然さを、日本語を話す人に文の自然さを見てもらう。
- 「한국어와 다른 점」の補足（`scripts/same-hanjaeo.json`）と韓国語の意味の直しも、AI が書いて一件ずつ確かめたもの。韓国語を話す人に、
  補足の言い方と、ちがいの見立て（細かすぎないか・足りない語はないか）を見てもらう。
- 「同じ意味」の判定は 한국어기초사전 の対訳から作っているので、入口（입구＝入口）や 휴식（休息）のように同じ意味なのに
  「한자가 같은 일본어」に入る語が少しある（逆に決めつけないよう、意味を並べて見せる）。
