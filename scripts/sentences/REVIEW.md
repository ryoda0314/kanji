# 書き足した例文の確かめどころ（hashi-ab.json）

`hashi-ab.json` の1,974文は AI が書いた下書き。機械で確かめたのは、目当ての語が文で出会う と同じ印の付け方で拾えること、
韓国語の訳に同じ漢字語か韓国語の意味の語が入っていること、長さ、ほかの文と重ならないこと（`check.mjs`）。
人の目で見てほしいのは次のところ。

## 1. 文ぜんたい

- 日本語：友だち・家族・同僚とのタメ口。言い回しの不自然さ、硬すぎる語。
- 韓国語：반말。日本語に忠実か。韓国語の漢字語を入れるために硬くなった訳がある（伝言 → 전언、容易 → 용이하게、母親 → 어머니、
  以来 → 이래、自動販売機 → 자동판매기）。
- 月と数は 칠월・팔월・일월・십일월・팔십 のようにハングルで書いた（検査が漢字語の形を求めるため。ふだんは 7월・80）。

## 2. 意味・使い方のちがう語

日本語と韓国語で意味・使い方のずれる漢字語は、画面に「한국어와 다른 점」として補足を出している（`../same-hanjaeo.json` の `kd`。
生徒 ↔ 생도、計算 ↔ 계산、議論 ↔ 의논 など643語）。その語の例文は、補足に合う意味で書いた（訳が韓国語にしかない意味になっていた文は直した）。

- 補足の言い方が自然か、細かすぎないか（ちがいを言うほどでない語に付いていないか）、抜けている語はないか。
- 一部だけ重なる語の例文（長官 ↔ 장관 は 国務長官 のように 장관 と訳せる場面、班長 ↔ 반장 は学校の 반장 と取られないか）。

## 3. 直した辞書のデータ

- 韓国語の意味の誤り（抵抗 に 저당、学者 に 학사、障害者 に 병신 のような差別語 など223語）は `../glosses-ko.json` の「_見直し」以下で直した。
- 読みによって韓国語と意味の合わない語（人事 ひとごと・一行 いちぎょう・大勢 おおぜい・一月 ひとつき・相対 あいたい など21語）は、
  同じ漢字語から外した（`same-hanjaeo.json` の `ks: false`）。その語の例文は書いていない（書いた 趣向・洞 ほら の文は外した）。
- 韓国語の語の形：到底 → 도저히、一斉 → 일제히、年度 → 연도。

## 4. 例文が2文に届かない語（7語）

- 形態素解析（kuromoji・IPADIC）がその読みを出さない：市場 いちば、上下 うえした、博士 はくし、故郷 ふるさと、一日 ついたち、対 つい。
- 女史：隣の人を 女史 と呼ぶ文（韓国語の 여사 の使い方）を外したので1文。

## 5. 検査の都合で、ふだんとちがう形にした語

- 漠然：漠然すぎる の形だけ（書いたときは 漠然と が一つの副詞として読まれて拾えなかった。印の付け方を直したので、いまは 漠然と でも拾える）。
- 支払・手続：送りがな無し（支払い・手続き は辞書では別の語で、漢字語に入っていない）。
- 積極 は 積極性、具体 は 具体例・具体案（積極的・具体的 は辞書では別の語）。
