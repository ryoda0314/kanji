# 말씨앗 — 紹介映像

アプリの映像。1920×1080・30fps・約92秒、字幕（韓国語）とナレーション（韓国語、Gemini TTS）。Remotion 4 で作る（アプリとは別の
プロジェクト）。ほかに、ホーム画面への追加のしかたの縦の映像（下の「ホーム画面への追加のしかた」）。作り方は姉妹アプリ ことのね の映像（`../../hanjaatume/promo`）にそろえた：アプリの画面を描き直し、その横に一文ずつ言葉を置く。

見る人：日本語の単語を一つずつ丸暗記している、韓国語を話す人。日本語の漢字語の多くは韓国語の漢字語と同じ漢字・同じ意味で、
足りないのは日本語の音だけ。その音は字ごとの 소리 짝（회 → かい）で、짝が集まるほど言える語がまとめて増える。それが、
そのままアプリになっていることを見せる。

数はアプリの辞書のとおり（`scripts/net.mjs` がアプリの `../public/data` から `src/net.json`・`src/demo.json` を作る。決まりはアプリの
`src/data/combine.ts`・`sounds.ts` と同じ：同じ漢字・同じ意味で韓国語でもよく使う語（`ks`、`kl` 4 まで、ほとんど使わない語を除く）を、
字ごとの 소리 짝 がすべて集まっていれば言える語に数える）。회・사・원 の三つで言える語は 회사・사회・회원・사원・회사원 の5語。
網の 24 の 소리 짝 で言える語は55語（網で言葉の札を出すのは、JLPT の一覧にある語だけ。ほかの語も線は光り、数には入る）。
「약 5,800개」は 同じ漢字・同じ意味で、韓国語で 초급〜고급 の語（`ks`、`kl` 3 まで。アプリの og:description と同じ数）。

## ナレーション

台本は `voice/lines.json`（画面の字幕とは別の、耳で聞く文）。韓国語の語り（V）に、日本語の語（J：かいしゃ・きょうかい…）が日本語の
発音で、画面にその語が出る時に一つずつ鳴る。日本語の語は韓国語の文に混ぜない（文ごと訳したり韓国語読みしたりする）。

- 声：Gemini TTS（`gemini-3.1-flash-tts-preview`、声 Kore）を Vertex AI で。鍵は ことのね・ことのは の映像と同じサービスアカウント
  （`GOOGLE_SERVICE_ACCOUNT_KEY`・`GOOGLE_CLOUD_PROJECT`・`GOOGLE_CLOUD_LOCATION`）。鍵はこのリポジトリに置かない。
- どのクリップも、作ったあと書き起こし（`gemini-2.5-pro`）で台本と比べ、合うまで作り直す（日本語の語は一字も違わないこと、韓国語の
  語りは5%まで）。「공부는, 일본어로」は、続きの「べんきょう」まで言ってしまったテイクがあった（書き起こし「벤쿄」）。
- 映像の時は、声の長さから決まる（`src/voice.json`。`src/timeline.ts` は声が言い終わってから次へ進む）。声を作り直したら
  `music` も走らせ直す。声のあいだは音楽が下がる（`src/Promo.tsx` の DUCKING）。
- 機械で確かめたのは、ヘッダ・レート（24kHz モノラル）・ピーク・頭の無音と、書き起こし。耳で聞いての確かめ（声の感じ・速さ・
  韓国語と日本語の発音の自然さ）は、機械ではできない。

## ホーム画面への追加のしかた（src/Install.tsx）

縦の映像（1080×1920）。字幕・ナレーション・電話の画面の言葉は、すべて韓国語。ことのね の同じ映像（`../../hanjaatume/promo` の
`src/Install.tsx`）と同じ流れ・同じ絵で、言葉だけを韓国語に、アプリの画面を 말씨앗 の 모으기 にした。

X のリンクから開いた人は、X の中のブラウザで開いている。そこではホーム画面に追加できないので、まず Safari（Android は Chrome）で
開き直し、それから追加する。iPhone（下のアドレスの「⋮」→「브라우저에서 열기」→ Safari のアドレス欄の左はしの「≡」→「공유」→
「더 보기」→「홈 화면에 추가」→「추가」）、Android（下のアドレスの「⋮」→「브라우저에서 열기」→ Chrome の右上の「⋮」→「홈 화면에 추가」→
「설치」）の順に、指で押すところを見せる。メニューに見つからないときは、リンクをコピーしてアドレス欄に貼り付ける。

- 縦の映像。X の自動再生は音なしなので、説明はすべて字幕にも出す。ナレーションは `voice/lines.json` の I01〜I17（I03 は欠番。
  ことのね と同じ ID）で、映像の時は声の長さから決まる（`src/installTimeline.ts`：指で押すのは、声が「누르고」「골라요」と言う
  ところ。クリップの長さの割合で置いているので、言い方を変えたら割合も合わせる）。声のあいだは音楽が下がる。
  音楽はこの映像の長さに合わせて別に作る（`public/sound/music-install.wav`、`npm run music`）。사파리・크롬・엑스・아이폰・
  안드로이드 はハングルで台本に書く。
- X・Safari・Chrome の画面は形だけをまねた絵で、ロゴは描かない。メニューの言葉は、韓国語に設定した電話のものを書いたが、
  **実機では確かめていない**（とくに X の「⋮」の中身「공유하기・브라우저에서 열기・링크 복사하기」と、iOS 26 の共有シートの
  「더 보기」）。版によっても違う（Chrome の「홈 화면에 추가」と「앱 설치」）ので、字幕で「〜라고 나올 수도 있어요」と添えている。
  韓国語の電話で確かめて、違っていたら `src/Install.tsx` の絵と字幕（STEPS）を合わせる。
- アドレスは公開先が決まっていないので `vercel.app` だけ（`src/Install.tsx` の ADDRESS）。決まったら書き換える。

## 作り方

```bash
cd promo
npm install
npm run net        # 映像の語と数（アプリの辞書 ../public/data から src/net.json・src/demo.json を作る）
npm run assets     # アプリのアイコンと字（Google Fonts の倉庫から取り、映像に出てくる字だけに切る。Python の fontTools）
npm run voice -- --env ../../english/.env.local   # ナレーション（まだ無いクリップだけ。--force・--only V01,J01・--check）
npm run music      # 音楽と小さな音（Python と numpy。映像の区切りに合わせて作る）
npm run studio     # 見ながら直す
npm run render     # out/malssiat-promo.mp4
npm run install-video   # ホーム画面への追加のしかた out/malssiat-install.mp4（縦 1080×1920）
npm run stills -- 300 1150     # 1コマだけ out/stills に（COMP=Install でホーム画面への追加のしかたから）
```

- 画面はアプリの CSS と文言（`../src/copy.ts`）から描き直している（`src/ui.tsx`、`src/scenes/`）。アプリの見た目や言葉を変えたら、
  ここも変える。
- いつ何が起きるかは `src/timeline.ts`。打つ長さは打ち方（`src/anim.ts` の koTyping・jaTyping）から決まる。ハングルは字母を一打ちずつ
  （회의 は ㅎ → 호 → 회 → 횡 → 회으 → 회의）、日本語はローマ字で打ってかなに変わる（kyoukai → きょうかい）。時を変えたら `music` を
  走らせ直す（音楽の最後の和音が終わりのカードに落ちる）。
- 字はアプリと同じ（IBM Plex Sans KR・IBM Plex Sans JP・Noto Serif JP・Noto Serif KR・고운바탕）。言葉を変えたら `assets` を走らせ直す。
- 音楽と小さな音は `scripts/music.py` が作る（ことのね の映像と同じもの）。だれかの曲は使っていない。
- 色は `remotion.config.ts` で bt709・yuv420p にしている（ことのね と同じ。全範囲の yuvj420p だと薄い灰色が白く飛ぶ）。
